## Descripción

El sistema permite buscar películas por título, sinopsis, tag o fragmento de texto, mostrar resultados ordenados por relevancia, visualizar la sinopsis de cada película, guardar películas en una lista "Ver más tarde" y recibir recomendaciones personalizadas basadas en los Likes del usuario.
